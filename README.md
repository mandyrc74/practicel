# PractiCel

Aprende Excel practicando, 5 minutos al día. App de pago: solo la primera lección es gratis.

Este repositorio publica con GitHub Pages:
- `index.html`: página de lista de espera.
- `prueba/`: prototipo con la lección gratis "Tu primer presupuesto en 5 minutos".

Excel es una marca de Microsoft; PractiCel no está afiliada a Microsoft.
